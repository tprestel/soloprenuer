# TabSnap — Chrome Web Store Listing

## Name
TabSnap — Full Page Screenshots

## Short Description (132 chars max)
Capture full-page screenshots of any tab. Download as PNG, JPG, or PDF — instantly, with no sign-up required.

## Detailed Description
TabSnap lets you screenshot an entire web page — not just what's visible, but the whole scrollable page — in one click.

**How it works:**
1. Click the TabSnap icon
2. Choose PNG, JPG, or PDF
3. The full page is captured and downloaded to your computer

**Why TabSnap:**
- Full-page capture (not just the visible viewport)
- Three export formats: PNG, JPG, PDF
- Batch capture entire sites from their sitemap — pick pages from a path tree and capture at desktop and/or mobile widths into one folder
- No account, no cloud, no data collection
- Works on any page

**Privacy:** TabSnap captures nothing unless you click it. No browsing data is stored or transmitted.
